# T11–T15 Next Wave Plan

> **For agentic workers:** T11 is BRAIN-only TDD. Only `extension/src/agent/workflow_memory.ts`, `extension/tests/unit/scalemcp-topk.test.ts` may be touched. No new deps, no secrets, no network, 0 LLM calls.

**Goal:** Bound ScaleMCP recall with an explicit top-k seam (`queryTopK` / `topK` param) so large parent_child indexes return a small deduped set without reordering RRF-60 fusion or breaking FLAT fallback.

**Architecture:** Pure helpers + thin `HybridRetriever` seam in `extension/src/agent/workflow_memory.ts` reusing `resolveParents` (parent-resolve dedupe before slice), `RRF_K=60` fusion, `FLAT_FALLBACK` linear scan. `normalizeTopK` clamps `≤0`/`NaN`/non-finite to default 5. Empty index → `[]`. `query`/`queryCascade` share the same normalizer; `queryTopK` is a thin delegate (no forked ranking).

**Tech Stack:** TypeScript, Vitest, existing `extension/src/agent/workflow_memory.ts` (`HybridRetriever`, `RRF_K`, `FLAT_FALLBACK`).

Spec: `docs/plans/2026-11-15-t11-t15-next-wave.md` (this file — Goal/Architecture/Constraints/Review Focus §§, T11 Files + Verify).

**Constraints:**
- BRAIN-only: no new deps, no network, no secrets in code/tests/artifacts.
- Deterministic: same index + query → same order; dedupe before slice (parent wins, best-score first).
- Fail-closed: empty index → `[]`; bad `topK` (`≤0`, `NaN`, non-finite) → default 5, never `[]` by accident or unbounded.
- 0 LLM calls (pure stub; no model/provider import).
- Lean: minimum code that passes; out-of-scope files untouched.

**Review Focus:**
- `normalizeTopK` returns 5 on `undefined`/`≤0`/`NaN`/non-finite, `Math.floor` otherwise.
- `query`/`queryCascade` slice after `resolveParents` (dedupe before bound), `length ≤ topK`.
- `queryTopK` delegates to `query` (no ranking fork); RRF-60 + FLAT preserved.
- `npx vitest run tests/unit/scalemcp-topk.test.ts` EXIT:0; `npm run typecheck` EXIT:0.
- No secrets in plan/progress/evidence/test.
