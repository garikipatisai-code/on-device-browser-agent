# T16–T20 DAG Dispatch Plan

> **For agentic workers:** T16 is BRAIN-only TDD. Only `extension/src/agent/orchestrator.ts`, `extension/src/shared/messages.ts`, `extension/src/agent/budget.ts`, `extension/tests/unit/t16-flags-dag.test.ts` may be touched. No new deps, no secrets, no network, 0 LLM calls.

**Goal:** Put the T6 DAG seam (`parseDagPlan` / `dispatchDagWave` / `joinVarRefs`) behind a default-off `Settings.dagDispatch` flag with wave-aware dispatch (`wavesFor` + `dispatchDagPlan`), so the off path stays byte-identical legacy sequential while the on path dispatches dependency waves in input order with sequential fallback and a shadow log.

**Architecture:** Pure helpers in `extension/src/agent/orchestrator.ts` reusing `dispatchDagWave` (parallel `Promise.all`, input-order results, sequential fallback). `wavesFor` topologically groups steps into waves (input order preserved); fail-closed (`[]`) on cyclic / self / dangling `needs` or duplicate ids. `dispatchDagPlan(steps, run, { enabled, emit })` is the wiring: off → verbatim sequential loop; on → per-wave `dispatchDagWave`, cyclic/invalid → sequential fallback + shadow `log` warn. Flag `dagDispatch?: boolean` on `Settings`, `false` in `DEFAULT_SETTINGS` (safe by default, mirrors `structuredToolCalls`/`limitedResources`).

**Tech Stack:** TypeScript, Vitest, existing `extension/src/agent/orchestrator.ts` (`dispatchDagWave`, `DagStep`), `extension/src/shared/messages.ts` (`Settings`, `DEFAULT_SETTINGS`).
